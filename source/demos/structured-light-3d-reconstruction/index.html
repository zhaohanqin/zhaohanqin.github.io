结构光三维重建系统

一套代码里跑着两条完整链路：单相机 + 单投影仪 的标准面结构光系统，与 左右双相机 的双目分支。它们在标定阶段分叉——一条标定“相机-投影仪”，一条标定“相机-相机”——随后在相位解码与三维重建处汇合。

输入
标定板图、相移条纹序列
链路
相机-投影仪 / 左右双相机
输出
深度图、有效掩码、PLY 点云

演示边界：这是基于仓库中两个真实 PyQt5 程序（结构光系统UI、双目结构光系统UI）的真实界面截图与真实运行产物整理的静态讲解页，不上传图像、不调用模型，也不在浏览器中执行标定。

        03 / 标定为什么不同

        投影仪不会“看”，双目却有两双眼睛

        两种标定都求解“成像设备对”的相对姿态，但获取对应点的方式完全不同。投影仪是输出设备，无法直接拍照：必须向标定板投射已知条纹，再用绝对相位把相机角点反算成 DLP 像素坐标，相当于把投影仪伪装成“逆相机”参与标定。双目系统里两个相机都能直接看到同一块标定板，各自检测角点即可，不需要条纹和相位。

        单目 · 相机-投影仪联合标定

        1. 1拍摄每个姿态的标定板图 + 水平/垂直条纹图，按 13 个位姿分组。
        2. 2相机直接检测圆点/棋盘格角点，得到相机像素坐标。
        3. 3用 N 步相移 + 三频外差恢复绝对相位，把每个相机角点插值映射到 DLP 像素坐标。
        4. 4把投影仪当作逆向相机，与相机做 stereoCalibrate，求 Kc、Kp、R、t、F，并按投影仪重投影误差过滤坏点。

        代码：结构光流程/相机投影仪的标定.py → CameraProjectorCalibration；DLP 反投影误差 0.224 px。

        双目 · 左右相机标定

        1. 1左右相机同步拍摄同一组标定板姿态，左右目录文件一一对应。
        2. 2左右分别做灰度翻转/归一化预处理并检测圆点，得到左右角点集。
        3. 3先用每张图的单应性分别标定左右内参，再 stereoCalibrate 求相对 R、t。
        4. 4输出左右内参/畸变、相对位姿、基础矩阵 F 与基线距离。

        代码：双目结构光三维重建/双目相机标定.py → StereoCameraCalibration；基线 112.24 mm。
