结构光在普通漫反射表面上可以形成稳定条纹，但高反射表面会带来高光饱和、局部对比度消失和条纹形状扰动。相移算法随后看到的已经不是理想正弦信号，包裹相位与绝对相位都可能被污染。

Y-FFC 项目的定位，是在相位解码之前加入一个学习式的灰度条纹恢复/分解阶段。它不是直接输出三维点云，也不能仅凭模型代码证明重建精度提高；它实现的是一套从受干扰灰度图到恢复图、亮成分、梯度与高光先验的多输出网络，以及与之配套的训练、消融和滑窗推理工程。

## 项目概览

| 项目要素 | 内容 |
|---|---|
| 项目目的 | 分离高反光条纹中的镜面成分并恢复漫反射条纹，为后续物理相位分析提供更可用的输入；网络本身不直接产生点云。 |
| 核心输入 | 配对的高反光输入/漫反射目标（本地 data/data2/data3 各 4802 对，128×160 灰度图）；推理 checkpoint 与单张或批量图像 |
| 核心输出 | 漫反射 r、镜面分量 b、梯度 g、高光概率 s、对比图及下游相位分析图 |
| 项目重点 | 核心不是堆叠网络名，而是同时保持局部条纹、较长范围上下文和高频结构，再用"物理减法 + 学习恢复"双路径降低单一路径误差。 |

## 任务定义：恢复与三维重建是两件事

设受反射干扰的单通道条纹图为 `x`，配对的目标图为 `y`。网络希望输出恢复结果 `r`，同时显式预测亮成分 `b`、梯度先验 `g` 和高光可能性 `s`。

数据流可以写成：

```text
受干扰条纹 x
  -> 多尺度局部/全局编码
  -> 梯度与高光辅助分支
  -> 亮成分 b + 直接恢复 r_direct
  -> 物理式相减路径 r_sub
  -> 学习融合与残差精修
  -> 最终恢复 r
```

这里必须明确三个边界：

1. `r` 是图像恢复结果，不是绝对相位。
2. `s` 是网络内部的高光似然输出，当前没有校准证据，不能解释为严格概率。
3. 只有在同一标定、同一相移序列和同一重建配置下比较原始/恢复后的相位与点云，才能讨论它对三维重建的影响。

## 监督信号从哪里来

主数据路径使用成对图像。代码根据输入与目标构造两个辅助监督量。

### 亮成分代理

$$
b_{\mathrm{gt}}=\mathrm{clamp}(x-y,\,0,\,1)
$$

这个定义隐含了“干扰主要是附加亮分量”的假设。若真实反射同时改变局部对比度、产生饱和裁剪或遮蔽原条纹，简单差值并不等同于物理反射层。因此本文把它称为训练代理，而不是普适光学分解定律。

裁剪还会丢弃所有负差值：当目标比输入更亮时，这部分信息不会进入 `b_gt`。这也是网络不能只依赖相减路径的原因之一。

### 梯度代理

代码对输入 `x` 计算 Sobel 梯度幅值并归一化：

$$
g_x=\mathrm{Sobel}_x(x),\qquad g_y=\mathrm{Sobel}_y(x),\qquad
g_{\mathrm{gt}}=\mathrm{normalize}\!\left(\sqrt{g_x^2+g_y^2}\right)
$$

需要注意，梯度目标来自输入图，而不是目标恢复图。它更像“当前图中哪里存在结构变化”的辅助信息，用于提醒主干关注条纹边缘和突变区域，而不是直接给出干净条纹的梯度真值。

## 为什么同时使用 ResNet、Swin 与 FFC

高反射干扰兼具局部和全局性质。尖锐高光是局部异常，而条纹的周期连续性和大范围照明变化需要更大的感受野。主模型把三类建模方式组合起来：

| 组件 | 擅长的信息 | 在当前模型中的角色 |
|---|---|---|
| ResNet50 编码分支 | 局部纹理、边缘和稳定卷积特征 | 提供 `H/4、H/8、H/16` 多尺度特征 |
| Swin-Tiny 分支 | 窗口内上下文与逐层扩大感受野 | 在相同尺度提供上下文特征 |
| FFC 模块 | 空间支路与频域全局混合 | 在解码/融合中处理长程周期结构 |

### 多尺度融合并非每层都一样

在较高分辨率的 `H/4、H/8` 层，代码采用门控残差式跳跃融合，让两种编码特征在保留原信息的同时相互注入。到 `H/16` 深层，模型使用更强的跨模态融合，并把深层信息以有界反馈方式传回上层。

这种设计体现了一个工程判断：浅层负责细节，不宜被复杂融合过度改写；深层语义更抽象，可以承担全局上下文组合。但当前没有对应消融结果，不能把这一判断写成“已经证明更优”。

### FFC 的频域路径做了什么

FFC（Fast Fourier Convolution）不是直接执行结构光相位解包裹。它对中间特征做实数 FFT，在频域进行可学习变换，再通过逆 FFT 返回空间域，与局部分支融合。

```text
feature
  -> spatial branch ------------------+
  -> rFFT -> learned transform -> iFFT +-> fused feature
```

它处理的是神经网络特征中的全局混合；后面损失函数中的“频域相位”也指图像频谱相角，不等同于结构光通过多帧相移解出的物理相位。把这两个“相位”区分开，是理解该项目的关键。

## 辅助先验如何进入主恢复路径

辅助解码器预测 `g` 和 `s`，并在多个尺度上把相关特征注入主解码器。主路径不是只在最后拼接两张图，而是在恢复过程中反复利用：

- 梯度信息提示可能的条纹边缘和结构位置；
- 输入亮度提供高光和饱和区域线索；
- `s` 参与调节增强特征的注入强度；
- 多尺度辅助特征与主干特征共同决定亮成分和恢复图。

这里的 `g/s` 是辅助任务：训练时用额外约束迫使网络学习可解释的中间表示，推理时又把这些表示反馈给主任务。它们的价值需要通过删除辅助分支的消融实验验证，而不能由结构图本身证明。

## 为什么最终输出不等于 `x - b`

模型先建立一个物理直觉较强的相减路径：

$$
r_{\mathrm{sub}}=\mathrm{clamp}(x-b,\,0,\,1)
$$

但 `b` 的误差会被一比一传给 `r_sub`，而裁剪到 0 的暗区信息无法恢复。为此，模型另设直接恢复头 `r_direct`，再学习一个融合系数：

$$
\alpha=\mathrm{sigmoid}(a),\qquad
r_{\mathrm{fused}}=\alpha\,r_{\mathrm{direct}}+(1-\alpha)\,r_{\mathrm{sub}}
$$

检查到的实现中，`alpha` 是学习得到的融合参数/门控量，但没有证据表明它经过不确定性校准，所以不能把它解释成置信度。

融合后还有残差精修：

$$
r=\mathrm{clamp}\!\left(r_{\mathrm{fused}}+0.15\,\delta\!\left(r_{\mathrm{fused}},x,r_{\mathrm{direct}}\right),\,0,\,1\right)
$$

这形成两种互补归纳偏置：相减路径保留“去除亮成分”的物理直觉，直接路径允许网络修复非加性失真，精修头再处理融合后的局部残差。项目已经准备了用于检验这一组合的消融变体，但没有提交结果。

## 复合损失约束了什么

训练目标不是单一 MSE，而是把多个目标分组：

| 损失族 | 约束对象 | 解决的训练问题 |
|---|---|---|
| 像素/结构损失 | `r` 与目标 `y` | 保持整体灰度和结构一致性 |
| 边缘损失 | 恢复图梯度 | 避免条纹边界被过度平滑 |
| 频域损失 | 图像频谱幅值与相角 | 约束周期纹理的全局频谱结构 |
| 感知损失 | 预训练特征 | 补充单纯像素差无法表达的结构 |
| 亮成分损失 | `b` 与 `b_gt` | 约束显式分解分支 |
| 梯度/高光损失 | `g、s` 与辅助目标 | 训练辅助先验 |
| 跨尺度/双输出损失 | 中间层与 `r_direct/r_sub` | 防止某一分支失去训练信号 |

代码中的频域目标使用 `rfft2`，包含幅值差和经过能量掩码的频谱相角一致性项。它在单张图像的二维频谱上工作，不是对多频相移序列执行异频解包裹。

部分损失权重会随训练阶段调整，某些可选感知项在预训练权重不可用时会退化或关闭。因此复现实验时必须保存实际启用项和权重调度，而不是只抄损失函数名称。

## 训练工程如何组织

根目录的统一模型与训练脚本是当前可追踪的主路径。训练流程包含：

1. 根据文件命名匹配输入/目标图像对；
2. 同步执行尺寸调整和几何增强，保证配对仍然对齐；
3. 可选生成合成高光，扩充干扰形态；
4. 自动建立训练/验证划分；
5. 为不同模块设置学习率组；
6. 使用梯度累积和有限值检查控制训练稳定性；
7. 维护 EMA（指数滑动平均）参数；
8. 验证时计算图像指标并保存可视化面板；
9. 保存普通权重与 EMA 状态供推理选择。

这些是脚本支持的能力，不代表某个完整训练已经在当前仓库中完成。仓库没有提交数据集、权重、日志或验证图。

另一个模块化目录的 README 声称可独立导入，但在当前提交和环境中，包导入会因为数据模块自导入、缺少导出符号而失败。为避免把文档意图当成事实，本文以根目录统一模型作为主路径，并把模块化版本视为尚待修复的拆分尝试。

## 原尺寸推理：滑窗不是简单切块

显存有限时，推理脚本把原图切成有重叠的 patch。默认重叠为 64 像素，并对每个 patch 使用 Tukey 权重窗：中心权重大，边缘权重小。所有 patch 预测累加后再除以权重和，从而降低接缝。

```text
for patch in overlapping_windows:
    pred = model(patch)
    output_region += pred * tukey_weight
    weight_region += tukey_weight

full_output = output_sum / weight_sum
```

推理还支持四种翻转的测试时增强（TTA）：分别预测、反变换后平均。它需要多次前向，计算成本会增加；仓库没有速度和收益测量，因此这里只说明实现，不引用注释中出现的预估增益。

权重加载会优先选择 EMA，同时允许部分兼容加载。后者方便架构演进，却有一个风险：若新参数没有从 checkpoint 恢复，它们可能保持随机初始化。实际部署必须检查缺失/多余键警告，不能只看到"模型加载完成"就认为所有层都已恢复。

仓库的 `ablation_experiment/` 为每个核心设计假设准备了严格的单变量消融：每组只移除一个模块/路径，其余结构、数据、增强、损失、种子（42）与训练配置保持一致。

| 实验 | 消融对象 | 检验假设 | 文件 |
|---|---|---|---|
| A | FFC 频域核心 → 等规模纯空间卷积 | 频域全局建模是否优于局部卷积 | `Y_FFC_no_frequency.py` |
| B | 梯度辅助臂（g/s 先验 + 三路门控） | 显式结构/高光先验是否优于隐式学习 | `Y_FFC_no_gradient.py` |

## 怎样设计一组可信的评测

要判断 Y-FFC 是否真的有价值，至少需要同一保留集上的完整协议：

1. 固定训练/验证/测试划分和随机种子；
2. 对基线及 A-D 使用相同训练轮数、数据增强和选模准则；
3. 报告全图 SSIM、PSNR、MAE，同时报告固定定义的高光区域误差；
4. 给出均值、离散程度和样本数量，而不是只展示最佳图片；
5. 至少展示一个失败案例；
6. 若讨论三维价值，对原始/恢复图使用完全相同的相位解码、标定、掩码、ROI 和三角化配置；
7. 保存相位误差、有效像素比例、点云误差以及所有 checkpoint/配置哈希。

## 项目当前的技术价值与限制

这个项目真正完成的是一套有明确研究问题的网络工程：局部卷积、窗口上下文、FFC 全局混合、梯度/高光辅助监督、物理式相减和直接恢复两条路径，被组织到一个可训练、可消融、可滑窗部署的统一框架中，并配套了三套配对数据集和四组单变量消融实验。

当前限制同样明确：监督代理依赖加性假设；默认 patch 设置与真实大图分布尚未验证；TTA 成本没有测量；部分 checkpoint 加载可能掩盖随机参数；模块化包当前不可独立导入；最关键的是没有任何可发布的实验产物。

所以这篇文章记录的是"模型为什么这样设计、代码实际做了什么、数据与实验如何组织、下一步应如何验证"，而不是一篇已经完成的性能论文。等补齐训练产出后，最重要的更新不是再增加网络结构，而是用同一批数据把图像恢复指标（SSIM/PSNR/MAE）、高光区域误差、相位误差和三维误差真正连起来，并给出 A-D 消融与 HDRNet/DCUNet 对比的结论。
