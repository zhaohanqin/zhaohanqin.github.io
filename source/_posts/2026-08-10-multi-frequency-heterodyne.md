相移法只能先算出取值范围在 $[0, 2\pi)$ 的包裹相位：每个像素只知道相位落在哪个周期内，却不知道到底是第几个周期。要把它变成可用于三维重建或面形测量的绝对相位，就必须做相位展开。这个项目是一套以**多频外差 / 塔形外差**为主线的脚本工具箱，把“条纹生成 → 单频包裹相位 → 多频展开 → 掩码/ROI → 误差分析 → 可视化导出”串成一条可重复的实验链。

## 原理：包裹相位为什么需要展开

### N 步相移

对一个固定频率，采集 N 张相位依次平移的条纹图。把第 $n$ 张图记为 $I_n$，N 步均匀相移时 $\Delta\varphi_n = 2\pi n / N$，包裹相位、调制度和平均强度按以下公式计算（与代码注释中的式 2.27–2.29 一致）：

$$\varphi(x,y) = -\arctan\frac{\sum_n I_n \sin\Delta\varphi_n}{\sum_n I_n \cos\Delta\varphi_n}$$

$$B(x,y) = \frac{2}{N}\sqrt{\left(\sum_n I_n\cos\Delta\varphi_n\right)^2 + \left(\sum_n I_n\sin\Delta\varphi_n\right)^2}$$

$$A(x,y) = \frac{1}{N}\sum_n I_n$$

其中 $\varphi$ 是包裹相位，$B$ 是调制度（条纹对比度），$A$ 是平均强度。单频解算只给出 $[0, 2\pi)$ 的相位，因此后续必须展开。

### 外差与参考展开

外差（heterodyne）的思想是：把两个频率的包裹相位相减，得到一个“等效低频”的拍频相位。频率越接近，拍频越低，越不容易出现周期判断错误；但拍频太低又损失测量分辨率。多频外差正是用“先保证可靠、再逐级提频”的方式兼顾两者。

给定一个低频参考相位 $\varphi_r$（频率 $f_r$）和目标相位 $\varphi_t$（频率 $f_t$），展开的关键是估计条纹级次：

$$k = \mathrm{round}\left(\frac{f_t}{f_r}\varphi_r - \varphi_t\right),\qquad \varphi_{abs} = \varphi_t + k$$

相位都按周期（归一化到 $[0,1]$）运算，最后再乘回 $2\pi$。$k$ 一旦判断错，结果就会差一个整周期——这正是后续噪声修正要处理的问题。

## 三频外差的展开路径

三频配置（如 81/72/64）在代码里有两种典型的展开方式，结构相同：

1. 先算两两外差：$\varphi_{12}=\varphi_{高}-\varphi_{中}$、$\varphi_{23}=\varphi_{中}-\varphi_{低}$，对应拍频 $f_{12}=f_高-f_中$、$f_{23}=f_中-f_低$；
2. 再做一次外差得到最低等效频率：$\varphi_{123}=\varphi_{12}-\varphi_{23}$，$f_{123}=|f_{12}-f_{23}|$；
3. 用最低等效相位做参考，展开 $\varphi_{12}$ 与 $\varphi_{23}$；
4. 再用展开后的两个中间相位分别展开中频相位，最后把两条路径的结果取平均，提高一致性。

实验分支的模块化版本还会对最低等效频率相位做一次高斯平滑并限制在 $[0,1]$，避免平滑把相位推到合法范围之外。主流程脚本的默认配置是 4 步相移、频率 81/72/64、垂直条纹，并支持通过掩码文件提取有效区域后保存全场与掩码区域的绝对相位。

## 频率设计：最大频率比与塔形外差

频率怎么选，直接决定展开可靠性。项目提供了三个层次的最大频率比（$\alpha_{max}$）公式，输入相位噪声标准差 $\sigma_\varphi$（以及塔形层数 $M$）即可计算：

| 方法 | 最大频率比公式 |
|---|---|
| 直接外差 | $\alpha_{max}=\sqrt{\dfrac{\pi^2}{9\sigma_\varphi^2}-1}$ |
| 层级外差 | $\alpha_{max}=\sqrt{\dfrac{\pi^2}{18\sigma_\varphi^2}-1}$ |
| 塔形外差 | $\alpha_{max}=\sqrt{\dfrac{\pi^2}{9\sigma_\varphi^2\,2^{M-1}}-\dfrac12}$ |

塔形外差把多级外差组织成“塔”状：经典塔形的物理频率序列是 $\{\alpha^2,\ \alpha^2+\alpha,\ \alpha^2+2\alpha+1\}$，最高频正好是 $(\alpha+1)^2$；对应的等效频率序列为 $\{1,\ \alpha,\ \alpha+1,\ \alpha^2,\ \alpha^2+\alpha,\ \alpha^2+2\alpha+1\}$。改进塔形在最高级引入 $\sqrt2$ 因子，得到另一组频率序列。

除了正向设计，工具还支持**由最高频率反解**：给定 $f_{max}$，经典塔形直接得到 $\alpha=\sqrt{f_{max}}-1$，改进塔形则解一个二次方程取正根；同时可以反解出该频率配置对应的相位噪声水平。例如 $\sigma_\varphi=0.1078$、$M=3$ 时，三种方法的 $\alpha_{max}$ 分别约为 9.66（直接）、6.80（层级）、4.81（塔形），塔形用更低的频率比换来了更宽松的频率组合。

| 层次 | 职责 | 典型内容 |
|---|---|---|
| 顶层通用工具 | 基础算法源与主流程 | 单频相位计算、三频可视化主流程、误差统计、频率设计 |
| 相位处理整理区 | 面向目录的批处理与后处理 | 批处理包裹相位、绝对相位误差比较、剖面/3D 可视化 |
| 实验分支 | 模块化与高精度展开 | 三频解包裹模块、高精度展开（大 k 修复）、塔形频率反解 CLI |

### 大 k 值下的噪声修复

高精度展开路径有一个很具体的工程点：当外差拍频很大时（例如频率组合中第二级外差的 $k$ 值达到 20 以上），相位差里的噪声会被 $k$ 放大，导致 `round()` 判断错误。实现里对这类情况先对相位差做**圆周高斯滤波**（分别滤波 $\cos$ 和 $\sin$ 分量再取角度），在不破坏 $2\pi$ 边界的前提下降噪，再做周期判断；展开完成后还有两轮 ±2π 跳变检测与修正。

背后的直觉是：两级外差的频率比分配决定了最终误差形态——第一级频率比小、第二级大时，最终相位以小幅误差为主；反过来则以大幅误差为主。因此高精度路径显式处理“跳级”误差，而不是只依赖平滑。

### 双路径平均

中频相位可以通过 $\varphi_{12}$ 和 $\varphi_{23}$ 两条路径分别展开再平均。两条路径的噪声来源不完全相同，平均可以降低单条路径的系统性偏差；实验分支的版本还会把结果按中频归一化，保证输出落在 $[0, 2\pi]$。

## 如何运行

仓库没有统一 CLI，属于“直接运行脚本 + 改配置区”的工作流。三个最常用的入口：

1. **三频主流程**：在脚本配置区填写条纹图像目录、相移步数 N、频率列表（默认 81/72/64）、条纹方向和掩码路径，运行后输出绝对相位、掩码相位及可视化图。
2. **单频批处理**：给定“总目录 → 一级子目录（频率+步数）→ 二级子目录（采集次数）→ 图像”的目录结构，自动按图像数量推断 N，批量输出包裹相位与调制度。
3. **塔形频率设计**：输入一个或多个最高频率（如 81、96、204），输出经典/改进塔形的物理频率序列、等效频率序列和反解的相位噪声水平。

依赖为 `numpy`、`opencv-python`、`matplotlib`、`scipy` 与 `Pillow`。多个脚本假定 Windows 环境并使用中文字体，交互式 ROI 选择还需要本地显示环境。仓库未附带 `requirements.txt` 与统一 CLI，建议先按 README 的阅读顺序熟悉脚本职责再运行。

需要先说清楚边界：仓库把所有结果类文件（`*.png`、`*.npy`、`*.mat`、`*.txt` 等）加入了忽略规则，因此**仓库本身没有附带任何真实测量结果**。下面能给出的验证只来自一次合成数据自检：
